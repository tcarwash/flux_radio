Startup artwork & legacy icons

FULL SCREEN ARTWORK

Standard Flux artwork from the 128 × 64 splash.bin. Raster-boot firmware displays this artwork directly; Designer enables optional voltage or message overlays and installed custom artwork. Older firmware requires the bitmap to be installed separately.

Legacy firmware only: startup icon

ICON STARTUP SCREEN

Only older firmware uses this icon when no full-screen bitmap is installed. Raster-boot firmware ignores theme startup icons; the legacy fields are retained for importing and exporting existing themes.
