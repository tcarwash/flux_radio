Module erasure is permanent. Cable protocol 2 firmware accepts only module slots (0–8 and 16–31), verifies the slot type, erases and reads back the entire 16 KB slot. Live module removal requires packed storage and does not reboot. If the inventory was read in explicitly selected legacy mode, removal also uses that mode and restarts the radio.
