# Flux Memories
Open the Memories tab in the local catalog. Enter coordinates (or use browser location on a supported secure origin), select a radius and band, and search HearHam for operational analog repeaters. Results are sorted by distance; source and distance are included in comments. The provider receives the catalog server's request for the dataset, not your search coordinates. Verify repeater settings before transmitting.

Add built-in packs or import CHIRP CSV / version 1 .fluxmem JSON. Edit the working list, remove unwanted channels, and export either format. CHIRP exports renumber locations from 1 in list order. The native format retains CHIRP field names, including tone and cross-mode settings. The working list is browser-local; export a backup. Receive-only packs use CHIRP Duplex=off. Marine pack is a small selection, not the full channel plan; channel 70 is DSC data, not voice.

Use **Read location from radio** to fill the repeater search from persistent APRS LAT/LON, not a live GPS fix. **Read memories from radio** uses the native capability-gated memory-bank reader and loads occupied slots 0–999 into the editable working list after confirmation. Duplicates already on the radio are retained. Add channels or imported packs, edit names, slots, frequencies and advanced tone fields, and export a portable backup. Both reads require a selected cable and may restart the radio when the cable session closes. The location reader checks the Aura storage marker and wear-leveled settings CRC. Decode failures are reported before replacing the working list. CHIRP exports renumber locations; native packs retain slots. CHIRP export does not imply CHIRP supports Flux firmware.

## Native radio programming (development checkpoint)
Base builds enable memory protocol v1 (0x90–0x94): 1000 native 32-byte records, staged 4 KiB sector writes and complete readback. Merge preserves occupied records, Replace requires confirmation. The 24 reserved records remain untouched. The host stores original/target banks and a recovery journal under `~/.local/share/flux/memory-backups`; Resume requires matching port/calibration and checksums. Power-cut recovery was tested with a host fault model; physical radio testing remains pending. RX-only records use zero TX frequency and the native reverse path refuses reversal. Do not treat this as physical TX-inhibit certification. Unsupported modes and nonrepresentable values are refused. Readback is a portable representation, not a lossless export of every proprietary field; retain binary backups.
