# Flux Whisper8 v0 — narrow eight-tone experimental modem

Date: 2026-11-23 (Pacific). Worktree: `/storage5/dev/flux-whisper8-mfsk-offline`
Branch: `research/whisper8-mfsk-offline-20261123`.

**Strictly OFFLINE. No hardware radio, SDR device, UART, SPI or RF emission accessed.**
**NOT Olivia-compatible**: we borrow Olivia 8/250's approximate symbol timing
and tone count only, not its interleaver, Walsh/sequence FEC, or acquisition protocol.
This is a test vehicle for the B-chip's proven `REG_70/71` audio-tone FM path.
**Do not describe synthetic noise success as over-the-air weak-signal sensitivity.**

## Reference waveform and message transfer

- Sample rate 8,000 Hz; symbol duration 256 PCM samples = **32 ms**, symbol rate **31.25/s**.
- Eight equally spaced audio tones **1125, 1156.25, 1187.5, 1218.75,
  1250, 1281.25, 1312.5, 1343.75 Hz** (span 218.75 Hz). Total tone
  center-to-center span 218.75 Hz; "250 Hz" refers to nominal Olivia-style
  channel designation, **not** measured occupied bandwidth.
- `REG_71` candidate words generated by the same floor-quantizing expression
  as Flux's existing `c/k6/mod/tonewr.c`: `floor(hz * 1032444 / 100000)`.
  Words: **11614, 11937, 12260, 12582, 12905, 13228, 13550, 13873**.
  Quantization and real audio filter/group delay must still be measured on RF.
- Public acquisition header: 12 alternations `0,7` followed by a fixed
  12-symbol sync. Fixed known preamble+sync is **not** a claimed
  fading-resistant acquisition algorithm.
- Offline text packet: one byte length (0..48), payload, CRC16-CCITT-FALSE.
  Three bits per tone, with **repetition-3 per 3-bit tone** as simple example FEC.
  This is an intentionally inefficient transport and **not** standard Olivia.
- `CQ AG7SU CN85` = **153 symbols / 4.896 seconds** on the host reference.
  Host receiver accepts variable sample start, detects all 24 public-header
  symbols, majority-decodes repetition, checks CRC. The tested fixture
  successfully recovered the message at deterministic audio-AWGN settings
  including **-8 dB audio sample SNR**. This SNR is not referenced to a
  2500-Hz RF noise bandwidth and does not imply a sensitivity threshold.

## Candidate physical fixture (not transmitted)

`c/k6/mod/whisper8_probe.c` is a **32-symbol / 1.024-second** known
radiated-TEST vector (not the text transmitter), with 24 public training symbols
and **8 reserved held-out symbols `1,4,6,2,7,0,3,5`**.
`whisper8_fixture.h` is reproducibly generated by:

```sh
python3 tools/k6_whisper8.py --header > c/k6/mod/whisper8_fixture.h
```

Module is **inert by default** and builds for B-chip Cortex-M0 Thumb:
`W8_BENCH_ENABLE=0` returns `-9` without any TX calls. Hardware-capable
compilation additionally requires explicit `W8_RF_ENABLE=1`,
`W8_DUMMY_LOAD_ACK=1` and `W8_WATCHDOG_ACK=1`.
It refuses non-0x4829, non-433.500MHz, busy channel, and key-down before
arming. It uses an existing 1800-ms firmware TX lease, PA OFF until explicitly
acknowledged test phase, `tx_pa(0)`, and register snapshot/readback and
`tx_off()` on cleanup. `REG_70/71` are restored and `REG_40/51` asserted
unchanged. **Compiled RF-capable code is not proof of a safe physical run**:
separately qualify target instruction timing/latencies, PIC linking, lease
duration and the external restoration harness before installing.

`tools/k6_whisper8_iq.py` consumes **saved**, complex 1.024-MS/s SDR IQ
(center 433.750 MHz, target 433.500 MHz, offset -250000 Hz), mixes and
downsamples it, FM-discriminates, then performs independent 8kHz spectral
classification at 256 samples/symbol. It acquires using **ONLY** the public
24 training symbols and scores **all eight held-out symbol IDs** without
re-optimizing against the holdout. A valid RF PASS will require all 8 exact
tone IDs, no ambiguous sync/frame candidates, stable clock/step timing,
a sensible positive tone-vs-runner-up separation and independent chip/PA
and restoration receipts. **Current scorer is a prototype** and must have
its numerical RF accept thresholds frozen *before any physical run*.
Record SDR carrier deviation, tone-frequency errors, harmonic/intermodulation
energy and noise baseline; packet-symbol accuracy alone does not establish
spectral cleanliness or Olivia interoperability.

## Reproduce offline qualification

```sh
python3 -m pytest -q tests/test_k6_whisper8.py tests/test_k6_whisper8_iq.py
python3 tools/k6_whisper8.py --message 'CQ AG7SU CN85' --snr-db -8
python3 tools/k6_whisper8.py --message 'CQ AG7SU CN85' --wav /tmp/flux-whisper8.wav
```

**19/19 tests PASS** as of this worktree write: reference packets,
repetition-3 correctable and CRC-rejected corruptions, message/audio recovery
with noise, default-inert Cortex-M0 compilation, explicit RF compile guards,
synthetic complex-IQ -> discriminator -> public-sync -> held-out-symbol scoring,
and negative missing-sync/modified-holdout controls.

This is **host-generated IQ**, not an actual physical RF capture. Tests use
compiled Cortex-M0 objects and host channel model, **not yet a compiled-module
Unicorn target-firmware execution**. That is a mandatory additional offline
gate before any real TX in the shared queue.

## Next scientific gates

1. Emulate the *compiled armed module* with timer, RFIC and PA restoration
   semantics and a hard TX cutoff; freeze exact source/ELF hashes.
2. Under a fresh separate approved `RADIO-EXCLUSIVE` lease and 50-ohm dummy
   load, perform exactly one short 32-symbol conducted-tone test with
   independent RTL-SDR capture, canonical nonblocking serial lock, trusted
   signed module backup, VFO restoration and TX-off verification.
3. If the 8/8 held-out RF tones pass with verified tone spacing and acceptable
   spurs/occupied bandwidth, port standard Olivia encoding/interleaving and
   test external fldigi interoperability *as a separate experiment*. If the
   tone phase or center frequencies drift, characterize before changing
   symbol rate or claiming weak-signal performance.
4. Then run controlled attenuation/noise measurements with preregistered
   packet error rate / Eb/N0 or SNR bandwidth definitions; do not extrapolate
   one noisy host frame to an RF link budget.
